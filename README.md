# Fear and Loathing Packing List

A checklist for packing the essentials for a trip to Las Vegas, inspired by Hunter S. Thompson's "Fear and Loathing in Las Vegas".

Not really intended to ever be used. This was just done as a test of [Typst](https://github.com/typst/typst).

I started out with a Typst template for a checklist called [Cheq](https://typst.app/universe/package/cheq) and then filled in the list of items (copied from [this page](ttps://www.thrillist.com/culture/hunter-s-thompson-quotes-on-how-you-should-be-drinking) since I didn't have the book handy). Then the most important part, I messed around with the formatting a little as a way of learning how to use Typst.
